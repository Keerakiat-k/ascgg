# Business Logic Workflows (โฟลว์การทำงานเชิงธุรกิจ)

เอกสารนี้รวบรวมลอจิกการทำงานและกฎเกณฑ์ทางธุรกิจที่ซับซ้อนของโปรเจกต์ ASCG_G

## 1. การสร้างรหัสพนักงานอัตโนมัติ (Employee Code Generation)
รหัสพนักงานไม่ได้ถูกสร้างแบบสุ่ม แต่มีรูปแบบ (Format) ที่กำหนดไว้ เพื่อระบุต้นสังกัดและปีที่เข้าทำงาน
- **Endpoint:** `GET /api/employees/next-code?prefix=XXX`
- **Format:** `[Prefix บริษัท][ปี พ.ศ. 2 หลัก][เลขรัน 3 หลัก]`
- **ตัวอย่าง:**
  - Prefix บริษัท: `CST`
  - ปีปัจจุบัน: 2026 (พ.ศ. 2569) -> เอาเฉพาะ `69`
  - เลขรัน (Running Number): หากคนล่าสุดคือ 001 คนต่อไปจะเป็น `002`
  - **ผลลัพธ์ที่ได้:** `CST69002`
- **ลอจิกในโค้ด:** ระบบจะดึงค่าจาก DB โดยใช้ `LIKE 'CST69%'` ดึงตัวล่าสุดมาแปลงเป็นตัวเลข บวก 1 แล้วประกอบกลับเป็นสตริง

## 2. ระบบ IT Helpdesk (การจัดการ Ticket)
กระบวนการแจ้งปัญหาไอทีมีวงจรชีวิต (Lifecycle) ดังนี้:
1. **พนักงาน (Employee):** กรอกฟอร์มแจ้งปัญหา (หมวดหมู่, ความเร่งด่วน, รายละเอียด) -> สถานะ Ticket จะเป็น `รอรับเรื่อง` (Pending)
2. **แอดมิน / ไอที (Admin/IT):** 
   - ระบบ Dashboard ของ Admin จะแจ้งเตือนจำนวนงานที่สถานะเป็น `รอรับเรื่อง` 
   - Admin เข้ามารับงาน กำหนด `assigned_to` -> สถานะเปลี่ยนเป็น `กำลังดำเนินการ` (In Progress)
3. **การปิดงาน:**
   - เมื่อแก้ไขเสร็จ Admin ใส่บันทึก `admin_note` -> สถานะเปลี่ยนเป็น `แก้ไขเสร็จสิ้น` (Resolved)
   - หากคำร้องไม่ถูกต้อง สามารถปรับสถานะเป็น `ยกเลิก` (Cancelled) ได้

## 3. การเพิ่มพนักงานใหม่ (Create Employee)
เนื่องจากระบบจัดเก็บข้อมูลแยกตามตาราง (Normalization) การสร้างพนักงาน 1 คน จึงต้องใช้ **Database Transaction** ในการ Insert ข้อมูลลง 5-6 ตารางพร้อมกัน:
1. `employees` (ข้อมูลพื้นฐาน - สำคัญที่สุด)
2. `employee_families` (ข้อมูลครอบครัว)
3. `employee_additional_info` (ทักษะและข้อมูลเพิ่มเติม)
4. `employee_educations` (ประวัติการศึกษา - วนลูป Array)
5. `employee_experiences` (ประสบการณ์ทำงาน - วนลูป Array)
6. `employee_trainings` (ประวัติอบรม - วนลูป Array)
*หมายเหตุ: หากการ Insert ตารางใดตารางหนึ่งล้มเหลว ระบบจะต้องทำ `ROLLBACK` ข้อมูลทั้งหมดเพื่อป้องกันข้อมูลกำพร้า (Orphaned Data)*

## 4. การจัดการสิทธิ์ผู้ใช้งาน (Role-Based Access Control - RBAC)
สิทธิ์ในระบบถูกแบ่งออกเป็น 3 ระดับ:
- `Role 1 (Admin)`: เข้าถึงได้ทุกเมนู รวมถึงการตั้งค่าระบบและจัดการระบบ IT Helpdesk
- `Role 2 (HR)`: จัดการรายชื่อพนักงาน ข้อมูลองค์กร และรับผิดชอบระบบวันลา
- `Role 3 (Employee)`: ดูข้อมูลส่วนตัว วันลาของตัวเอง สลิปเงินเดือน และแจ้งปัญหาไอที
