# โครงการ ASCG_G (HR & IT Support System)

## ภาพรวมของโปรเจกต์
โปรเจกต์นี้เป็นระบบ Web Application ภายในองค์กรที่เน้นด้านการจัดการทรัพยากรบุคคล (HR) และระบบแจ้งซ่อม/สนับสนุนด้านไอที (IT Helpdesk) พัฒนาด้วยสแต็ก MERN แบบปรับแต่ง (MySQL, Express, React, Node.js) 

## 1. โครงสร้างฐานข้อมูล (Database Schema)
ฐานข้อมูล `ascg_g_db` เป็นแบบ Relational Database (MySQL) โดยแบ่งกลุ่มของตารางได้ดังนี้:

### ระบบการจัดการพนักงาน (Employee Management)
เป็นส่วนที่มีขนาดใหญ่ที่สุด เก็บประวัติพนักงานอย่างละเอียด
- **`employees`**: ตารางหลักเก็บข้อมูลพื้นฐาน เช่น รหัสพนักงาน, ชื่อ, แผนก, ตำแหน่ง
- **`employee_credentials`**: ข้อมูลรหัสผ่านสำหรับล็อกอินเข้าสู่ระบบ (เข้ารหัสแบบ Hash)
- **`employee_additional_info`**: ข้อมูลเสริม เช่น ทักษะภาษา, ทักษะคอมพิวเตอร์, งานอดิเรก
- **`employee_addresses`**: ที่อยู่ปัจจุบันและตามทะเบียนบ้าน
- **`employee_educations`**: ประวัติการศึกษา
- **`employee_experiences`**: ประวัติการทำงานก่อนหน้า
- **`employee_families`**: ข้อมูลครอบครัว, บุตร, และผู้ติดต่อฉุกเฉิน
- **`employee_trainings`**: ประวัติการฝึกอบรม

### ข้อมูลพื้นฐานองค์กร (Master Data)
- **`companies`**: ข้อมูลบริษัทในเครือ (เช่น AEP, AGC)
- **`departments`**: แผนกต่างๆ ภายในบริษัท
- **`positions`**: ชื่อตำแหน่งงาน
- **`roles`**: สิทธิ์การใช้งานระบบ (Admin, HR, Employee)

### ระบบอื่นๆ (Other Features)
- **`announcements`**: ระบบประกาศข่าวสารและกิจกรรมภายในองค์กร
- **`it_supports`**: ระบบแจ้งซ่อมและร้องขอความช่วยเหลือด้านไอที (IT Helpdesk) เก็บรายละเอียดปัญหา สถานะการแก้ไข และผู้รับผิดชอบ

## 2. การทำงานของแต่ละโมดูล (Modules Overview)

แอปพลิเคชันถูกแบ่งการทำงานออกเป็นโมดูลหลักๆ ทั้งฝั่ง Frontend (React) และ Backend (Node.js/Express) ดังนี้:

### 2.1 โมดูลการยืนยันตัวตน (Authentication Module)
- **หน้าที่:** จัดการการล็อกอินและสิทธิ์การเข้าถึงระบบของผู้ใช้งาน
- **Frontend:** หน้าจอ `LoginPage.jsx` 
- **Backend:** ไฟล์ `routes/authRoutes.js` ทำหน้าที่ตรวจสอบชื่อผู้ใช้และรหัสผ่าน (Hash) และออก JWT Token สำหรับยืนยันตัวตน

### 2.2 โมดูลจัดการทรัพยากรบุคคล (HR Management Module)
- **หน้าที่:** เพิ่ม ลบ แก้ไข และแสดงรายชื่อพนักงาน พร้อมประวัติส่วนตัวแบบละเอียด
- **Frontend:** 
  - `EmployeeListPage.jsx`: แสดงรายชื่อพนักงานทั้งหมด (อาจมีฟังก์ชันค้นหา/กรอง)
  - `AddEmployeePage.jsx`: ฟอร์มสำหรับเพิ่มพนักงานใหม่
  - `EditEmployeePage.jsx`: ฟอร์มสำหรับแก้ไขข้อมูลพนักงาน
- **Backend:** ไฟล์ `routes/employeeRoutes.js` และ `routes/employees.js` ทำหน้าที่ดึงข้อมูลจากตารางพนักงานต่างๆ และบันทึกลงฐานข้อมูล

### 2.3 โมดูลแจ้งปัญหาด้านไอที (IT Support / Helpdesk Module)
- **หน้าที่:** ให้พนักงานสามารถเปิด Ticket แจ้งปัญหาคอมพิวเตอร์ และให้แอดมิน (IT) เข้ามาอัปเดตสถานะการซ่อม
- **Frontend:**
  - `ITSupportPage.jsx`: หน้าสำหรับพนักงานทั่วไปใช้แจ้งปัญหาและติดตามสถานะของตนเอง
  - `ITSupportAdminPage.jsx`: หน้าสำหรับแผนก IT ใช้ดูรายการปัญหาทั้งหมด อัปเดตสถานะ และมอบหมายงาน

### 2.4 โมดูลหน้าแดชบอร์ดและข่าวสาร (Dashboard & Announcement Module)
- **หน้าที่:** เป็นหน้าแรกหลังล็อกอิน แสดงภาพรวมและประกาศสำคัญของบริษัท
- **Frontend:**
  - `DashboardPage.jsx`: แสดงข้อมูลสรุป
  - `AnnouncementPage.jsx`: แสดงรายการข่าวสาร กิจกรรม (ดึงข้อมูลจากตาราง `announcements`)
